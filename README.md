# Diacritics, Not Paraphrase: Stress-Testing Vietnamese Scam SMS Filters Against LLM Rewriting

Code, LLM rewrites and results for the ICIIT 2027 submission by Phan Lê Văn Minh (University of Technology – The University of Da Nang).

## Contents

| Path | What it is |
|---|---|
| `data/sms_input.csv` | 2,598 de-duplicated messages derived from the Vietnamese Quality-Assured SMS Scam Dataset (Tran et al., CC BY 4.0, https://github.com/trannguyenthaituan251209/vietnamese_sms_dataset). URLs are replaced by `<URL>`. Columns: `id`, `message_id` (original id), `label` (1 = spam/scam), `text`. |
| `data/para_{qwen25_7b,seallm3_7b,nemo_12b}.csv` | Raw LLM rewrites (`raw`) and cleaned rewrites (`text`). `prompt` is `trung_tinh` (neutral, all messages) or `ne_loc` (evasive, positives only). |
| `data/labse_sim.csv` | LaBSE cosine similarity between each source and its rewrite, plus the quality-filter flag `hong` (discarded). |
| `scripts/` | Local CPU pipeline: data preparation, TF-IDF evaluation, bootstrap CIs, latency, tables and figure. |
| `kaggle/` | GPU scripts run on Kaggle (2×T4): rewrite generation, PhoBERT fine-tuning, LaBSE scoring and the CPU latency benchmark. |
| `results/` | Per-seed metrics, per-message predictions (`preds.csv.gz`) and confidence intervals. |
| `paper/` | LaTeX source. The tables and the figure are generated by `scripts/make_tables.py` and `scripts/make_figure.py`. |

Column and value names are Vietnamese:

| Name | Meaning |
|---|---|
| `sach` | Base model |
| `tang_cuong` | +Strip |
| `chuan_hoa` | Normalize |
| `tang_cuong_llm` | +LLM (leave-one-LLM-out) |
| `goc` | original message |
| `bo_dau` | diacritics stripped |
| `nguyen_van` | rewrite as generated |

## Reproduce

```bash
pip install -r requirements.txt
# 1. input for rewriting (from the original full_dataset.csv)
python scripts/prepare_para_input.py full_dataset.csv data/sms_input.csv
# 2. rewrites: run kaggle/viscam_para.py on a Kaggle GPU notebook with data/sms_input.csv attached
#    (the outputs are the data/para_*.csv files shipped here)
# 3. TF-IDF evaluation, main configuration and LaBSE >= 0.7 sensitivity analysis
python scripts/eval_para.py data/sms_input.csv data results/eval_para
python scripts/eval_para.py data/sms_input.csv data results/eval_para_labse70 data/labse_sim.csv 0.7
# 4. confidence intervals, latency, tables, figure
python scripts/ci_para.py results/eval_para/preds.csv.gz results/eval_para/ci.csv
python scripts/bench_tfidf.py data/sms_input.csv results/eval_para/para_all_checked.csv
python scripts/make_tables.py results paper/tables
python scripts/make_figure.py results/eval_para/preds.csv.gz paper/figures/recall_fpr.pdf
```

The PhoBERT results under `results/phobert_para/` and `results/phobert_extra/` come from `kaggle/phobert_para.py` and `kaggle/phobert_extra.py`. To regenerate them, run those scripts on Kaggle with `sms_input.csv` and `results/eval_para/para_all_checked.csv` (written by step 3) attached.
